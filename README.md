# Roleplay IA — downloads

Instaladores do **Roleplay IA**, um app de roleplay com IA (narrador, personagens, mundos e memória de longo prazo).

## Como baixar

Abra a página de [**Releases**](../../releases/latest) e baixe o arquivo da versão mais recente:

| Sistema | Arquivo | Modelos |
|---|---|---|
| Windows | `RoleplayIA-x.yyy.z-Setup.exe` | OpenRouter, proxies compatíveis com OpenAI e modelos locais (Ollama) |
| Android | `RoleplayIA-x.yyy.z.apk` | OpenRouter e proxies compatíveis com OpenAI |

O app já vem com o mundo **Reino de Aldoria** e a personagem **Erina** (com as expressões dela). Para conversar, cadastre um provedor em **Provedores** (por exemplo, uma chave do [OpenRouter](https://openrouter.ai/keys)).

### Windows
Execute o instalador. Se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo** (o instalador ainda não tem assinatura digital). Para atualizar, instale a versão nova por cima: campanhas e personagens são mantidos.

### Android
Abra o `.apk` no celular. Na primeira vez o Android pede para permitir a instalação de apps dessa origem (navegador ou gerenciador de arquivos). Para atualizar, instale o `.apk` novo por cima.
